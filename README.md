## About Me

I am a Computer Science Master's student at **ETH Zurich**, specializing in **Data Management and Machine Intelligence**. Previously, I completed my Bachelor of Science in Informatics at **Università della Svizzera italiana (USI)**, graduating *magna cum laude*.

My engineering and research interests bridge theoretical computer science, data-intensive systems, and modern full-stack development:

- **Data Systems & Internal Engines:** Query optimization, indexing strategies, distributed data architectures, and transactional processing.
- **Machine Intelligence & Search:** Multimodal information retrieval, dynamic topic clustering, propositional logic reductions to SAT solvers, and applied LLM workflows.
- **Systems Architecture & Full-Stack Engineering:** Modern reactive web architectures (Vue 3, React), strictly typed backend services (Spring Boot, FastAPI), automated CI/CD pipelines, and clean design patterns.

### ⚡ Algorithms, Theory & Data Systems

#### [OptiMove | SAT Logistics Solver](https://github.com/simo-macca/toc-movers-sat)
> A formal reduction and solver for the multi-agent "Movers" logistics planning problem, transforming spatial movement and carrying constraints into Propositional CNF to compute optimal schedules via Glucose-3.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![PySAT](https://img.shields.io/badge/PySAT-Glucose--3-7952B3?style=flat-square)
![Propositional CNF](https://img.shields.io/badge/Logic-Propositional_CNF-blueviolet?style=flat-square)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)
![Vue.js 3](https://img.shields.io/badge/Vue.js_3-4FC08D?style=flat-square&logo=vuedotjs&logoColor=white)
![Tailwind CSS v4](https://img.shields.io/badge/Tailwind_CSS_v4-06B6D4?style=flat-square&logo=tailwindcss&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)

- **Formal Theory Reduction:** Formulated a polynomial-time reduction encoding multi-agent movement, downwards-only carrying rules, and frame axioms across 13 constraint groups (A–M) into Conjunctive Normal Form (CNF).
- **Solving Engine:** Iterative deepening bounded SAT solver utilizing Glucose-3 (PySAT `IDPool`), isolated in child processes with defensive timeout guarantees.
- **Full-Stack Visualization:** FastAPI backend paired with an interactive Vue 3 elevator visualizer featuring real-time playback controls, action logging, and DIMACS formula export.
- **Links:** [Repository](https://github.com/simo-macca/toc-movers-sat)

> A classic arcade Snake game implemented in pure functional Racket adhering to the *How to Design Programs* (HtDP) methodology, featuring an immutable reactive event loop and dynamic difficulty scaling.

![Racket](https://img.shields.io/badge/Racket-Advanced_Student_Language-9B111E?style=flat-square&logo=racket&logoColor=white)
![GUI](https://img.shields.io/badge/GUI-2htdp%2Funiverse-brightgreen?style=flat-square)

## Academic Research & Thesis

### [PyTamaro-Web: Pedagogical Analytics & Static Code Analysis](https://simo-macca.github.io)
**Bachelor's Thesis in Informatics &bull; USI (Università della Svizzera italiana)**  
*Supervised at the Faculty of Informatics &bull; "From Raw Data to Pedagogical Insights"*

- **Research Scope:** Introductory programming platforms accumulate massive volumes of student code submissions without providing structured, actionable feedback to course instructors.
- **Methodology & Engine:** Designed and implemented an automated static analysis pipeline in Python that queries student submission databases and parses Abstract Syntax Trees (ASTs) to diagnose common conceptual misconceptions and syntax errors.
- **Instructor Dashboard:** Visualized aggregated student hurdle patterns and learning progression in an interactive pedagogical dashboard built with Tailwind CSS and Jinja2.
